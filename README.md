# DiskSweeper

Tool sederhana untuk membantu membersihkan file yang tidak diperlukan di Windows.

## Cara memakai

1. Download [`disksweeper.exe`](./disksweeper.exe) dari repository ini.
2. Simpan file tersebut di folder pilihan, misalnya `Downloads`.
3. Jalankan dengan double-click pada `disksweeper.exe`.
4. Ikuti petunjuk yang tampil di aplikasi.
5. Periksa kembali file atau folder yang dipilih sebelum menghapusnya.

> **Catatan:** Jangan menghapus file sistem atau file penting. Jika Windows menampilkan peringatan keamanan, pastikan file diunduh dari repository resmi ini sebelum memilih **Run**.

## Menjalankan dari terminal

Buka PowerShell pada folder tempat file disimpan, lalu jalankan:

```powershell
.\disksweeper.exe
```

## Persyaratan

- Windows
- Tidak membutuhkan instalasi tambahan
