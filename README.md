## ✨ Tentang aplikasi

DiskSweeper adalah aplikasi portable untuk membantu membersihkan file yang sudah tidak diperlukan di Windows. Tinggal download, jalankan, lalu ikuti petunjuknya—tidak perlu installer atau konfigurasi rumit.

## 🚀 Fitur utama

- 🪶 **Portable** — cukup satu file `.exe`
- ⚡ **Praktis** — langsung bisa digunakan setelah di-download
- 🛠️ **Tanpa instalasi tambahan** — tidak membutuhkan setup khusus
- 🛡️ **Kontrol tetap di tanganmu** — periksa kembali pilihan sebelum menghapus

## 📖 Cara memakai

1. Download [`disksweeper.exe`](./disksweeper.exe).
2. Simpan file di folder pilihan, misalnya `Downloads`.
3. Jalankan dengan double-click pada `disksweeper.exe`.
4. Ikuti petunjuk yang tampil di aplikasi.
5. Periksa kembali file atau folder yang dipilih sebelum menghapusnya.

> 💡 **Tips:** Tutup aplikasi lain yang sedang menggunakan file atau folder yang ingin dibersihkan.

## 💻 Menjalankan dari terminal

Buka PowerShell pada folder tempat file disimpan, lalu jalankan:

```powershell
.\disksweeper.exe
```

## ✅ Persyaratan

- Windows
- Tidak membutuhkan instalasi tambahan

## ⚠️ Catatan keamanan

Jangan menghapus file sistem atau file penting. Jika Windows menampilkan peringatan keamanan, pastikan file diunduh dari repository resmi ini sebelum memilih **Run**.

## 🆘 Troubleshooting

**Aplikasi tidak bisa dijalankan?**

- Pastikan menggunakan Windows.
- Coba jalankan kembali sebagai administrator jika diperlukan.
- Pastikan file `.exe` selesai di-download dan tidak terblokir oleh antivirus.

**Masih bermasalah?**
Buat [Issue baru](https://github.com/mrshollo/diskswep/issues) dengan menyertakan versi Windows dan pesan error yang muncul.
